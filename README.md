# Java Runtime Lab

Laboratorio personal de ASI-01 — Java e ingeniería del lenguaje, dentro de Formación Entrevistas. Permitirá estudiar progresivamente semántica Java, genéricos, colecciones, algoritmos, compilación, dependencias, concurrencia, Java Memory Model, Virtual Threads, Class Loading, bytecode, Garbage Collection, JIT, profiling, JMH y migraciones Java.

El laboratorio será independiente de Spring Boot. Sus ejercicios se vincularán a las unidades JAVA-01 a JAVA-30 según los objetivos de cada actividad. Más adelante podrá incorporar el proyecto integrador Java Runtime Lab de nueve etapas. La presencia de un ejercicio en este repositorio no acreditará por sí sola aprendizaje ni evaluación.

Cada práctica futura deberá identificar la unidad y competencia, las instrucciones para reproducirla y la revisión concreta del código mediante commit o etiqueta. Las evidencias, sesiones y resultados se registrarán en el repositorio académico, con enlaces a los artefactos técnicos reales.

Estado inicial: solo documentación mínima; sin código ni ejercicios implementados.

Consulte [docs/README.md](docs/README.md) para el alcance de la documentación técnica.
